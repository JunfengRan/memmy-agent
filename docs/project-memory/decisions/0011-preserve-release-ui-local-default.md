# ADR-0011：沿用 release 前端，仅接入本机项目记忆

- 日期：2026-11-13
- 状态：已采纳（用户明确纠正上一轮 UI 范围）
- 规格出处：v3 §3.2–3.4、§4.1；用户当日要求优先
- 替代：ADR-0010 中“新增记忆界面、项目内开关默认关闭”的体验决定，其余核心存储、归属、投递、重试规则保留。

## 决定

恢复 upstream/release/v1.2.7 原有项目看板、项目设置及样式。删除上一轮新增的项目记忆按钮、开关、弹窗、样式和专用前端 client；不重做原来的任务和项目交互。前端只在既有入口锁定上传云端：新项目默认仅本机，不允许开启共享；已有任务的共享按钮禁用，过期草稿共享意图不会触发上传。

共享契约的 PROJECT_CLOUD_UPLOAD_ENABLED 固定为 false，在应用装配处同时控制 UI 和 Backend。Backend 的 Collab cloud transport 在 allowCloudWrites=false 时拒绝一切非 GET 请求，即使存在登录凭据也不执行 fetch。原有只读协作记录及独立组件的交互能力保留，不将模型的远程推理调用混同于项目数据上云存储。

后端启动采集后，为尚未绑定的本机项目自动调用既有 create/space 并持久化绑定，沿用原有项目与任务 ID，无需新增前端控件。新轮次继续用已保存 JSONL、原始时间和幂等投递。已显式关闭的旧绑定不会被后台重复开启；历史不会自动导入。已有读取、导入、重试 API 保留，但本轮不再增加对应的新界面。

## 模型配置与验证

通过 Memmy 正式模型目录接口导入用户指定的 ~/.deepseek.env，保留旧模型，将 deepseek-v4.1-flash-1017 设为 BYOK Agent、memorySummary、memoryEvolution 的默认模型。实际服务确认摘要/演化模型已加载，存储与 embedding 仍为本地。密钥仅在用户配置中，不进入仓库。

连接测试、真实 chat completion 和独立数据库的一轮真实模型整理/召回均验证；不将一次合成冒烟写成质量指标。详见 metrics R-20261113-02。

自动绑定以本次后端启动时刻为新轮次采集下界，避免用户新建项目后在首次轮询前发送的第一轮被漏掉；启动前的历史仍不自动导入。已经持久化的旧绑定维持原有时间边界。

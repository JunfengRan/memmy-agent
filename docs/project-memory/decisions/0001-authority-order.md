# ADR-0001：规格权威顺序

- 日期：2026-11-03
- 状态：已采纳
- 规格出处：`design-docs/standard/` 三份文档

## 背景

PRD（修订至 11/03）、SDK 接口规格（修订至 10/30）和架构文档 v3（11/02 评审稿）之间有多处不一致，例如领域由谁判定、经验是否带历史、会话开始用哪个接口。项目记忆的实现方是算法侧，对架构设计负责。

## 决定

冲突时按以下顺序取舍：

1. 最新版架构文档（当前 v3；出现 v4 后 v4 自动成为最高权威）；
2. SDK 接口规格；
3. PRD。

架构文档没有写到的地方，按 SDK 规格；SDK 规格也没有的，按 PRD。所有差异登记在 `spec-alignment.md` 第二节。

## 影响

- domain 由调用方指定，经验带 history，不做模型重排，按架构文档实现。
- 两份产品文档之间的冲突（如 `create_space` 入参），以较新的修订为准，并登记到 open-questions 等待架构文档确认。

- 项目记忆对检索和回答的贡献明显（回答分 0.967 对 0.100），但写入质量的 Entry F1 只有 0.237。

- 模型只归出 5 个 topic（gold 7 个），B-cubed P 0.707 说明存在错误合并。
- trap rate 0.519 偏高，和旧实现把整个主题的所有条目都返回有关。
